Viu // Ultimate Social Network v12.0 Hyperion Edition
=====================================================
Files included in this package:
1. index.html - Complete UI structure, Modals, Arcade Lounge & Navigation
2. style.css  - Multi-Theme Stylesheet (12 Cyber & Social Themes + Animations)
3. script.js  - Application Engine (Firebase + LocalStorage, WebRTC Calls, Reels, Arcade & AI Tools)

How to Run:
- Extract all 3 files into the same folder.
- Open index.html via a local web server (e.g., VS Code Live Server, Python http.server, or any static host) so ES Modules (script.js) load smoothly.
